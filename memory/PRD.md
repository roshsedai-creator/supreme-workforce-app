# Supreme Hospitality SOPs & Compliance Document Generator

## Overview
A web-based application for Supreme Hospitality to generate, manage, and export Standard Operating Procedures (SOPs) and compliance checklists for the hospitality industry. The app uses AI (GPT-4.1) to generate professional, industry-standard documents.

## Features

### Core Features
1. **AI Document Generation** - 3-step wizard to generate SOPs and compliance checklists
   - Choose document type (SOP or Checklist)
   - Select from 8 hospitality categories
   - Enter title, requirements, and section count
   - AI generates comprehensive, professional content using GPT-4.1

2. **Document Management** - Full CRUD for generated documents
   - Search and filter by category, status
   - View document details in built-in viewer
   - Publish/unpublish documents
   - Delete documents

3. **Branded Export** - Export documents as branded HTML
   - Supreme Hospitality header and branding
   - Professional layout with sections
   - Print-ready with @media print styles
   - Confidential footer

4. **Dashboard** - Overview of all document activity
   - Stats cards (total, published, drafts)
   - Category grid with document counts
   - Recent documents list
   - Quick generate CTA

### Document Categories
1. Housekeeping SOPs
2. Food & Beverage SOPs
3. Front Office SOPs
4. Health & Safety Compliance
5. Fire Safety
6. HR & Employment
7. General Operations
8. Guest Experience

### Authentication
- Phone + PIN login
- Admin role support

## Tech Stack
- **Frontend**: Expo (React Native), TypeScript, Zustand
- **Backend**: FastAPI, Python
- **Database**: MongoDB
- **AI**: GPT-4.1 via emergentintegrations
- **UI**: Premium design with LinearGradient, Ionicons
